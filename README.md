# CS23I1012_ASBD_Endsem_Project
Project Title

Descriptive and Predictive Analytics on Cargo 2000 Freight Tracking and Tracing Dataset
Dataset

The project uses the Cargo 2000 Freight Tracking and Tracing dataset obtained from the UCI Machine Learning Repository.

Dataset Link: https://archive.ics.uci.edu/dataset/382/cargo+2000+freight+tracking+and+tracing

Project Description

This project performs descriptive and predictive analytics on shipment tracking data. It includes data cleaning, preprocessing, visualization, association rule mining, classification and performance comparison using PySpark.

Techniques Implemented

Data Cleaning and Preprocessing

Descriptive Analytics and Data Visualization

Apriori Association Rule Mining

Naive Bayes Classification

COFI Closed Frequent Itemset Mining

PySpark FP-Growth

PySpark Naive Bayes

Performance Comparison between Python and PySpark
